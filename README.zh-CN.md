# wallpaper-stage

**给住在桌面上的角色一个舞台。**

[English](README.md)

桌面伴侣首先是个调度问题，其次才是美术问题：循环一条长视频，她像屏保；
随机播片段，她像坏了。真正读作"活着"的结构是：

- **待机 = 短的无缝循环**（眨眼+呼吸，3–6 秒），安静轮换
- **反应 = 一次性片段**，由点击/事件触发，播完把控制权交回待机，且回到离开时的那一条
- **角色可点击**——在 Lively Wallpaper 里这意味着壁纸必须是 **HTML**：
  纯视频壁纸根本收不到鼠标事件

本库把这套逻辑做成测过的零依赖核心 + 可直接用的 Lively 模板：

- 🎬 `Stage`——待机轮换、反应打断/排队、防连点频闪的冷却
- 🎯 `createHotspots`——归一化坐标（与分辨率无关）的点击热区，带层级
- 🖥️ `template/`——能跑的 HTML 壁纸：视频层、热区层、可接任意对话/TTS 后端的聊天条

## 素材经验（踩坑得来）

- 待机循环首尾必须是同一帧状态，否则接缝就是故障感；循环内眨眼 3–6 秒一次、不规律
- 大动作（挥手、转身）绝不要放进待机组——循环一分钟就机械了
- 所有片段背景必须锁死，背景一漂，"她和你在同一个房间"的错觉立刻破
